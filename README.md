# Сложно сосредоточиться

Учебный проект Яндекс Практикума: адаптивная вёрстка сайта «Сложно сосредоточиться» в тёмной и светлой темах с автоматическим переключением по системным настройкам и принудительным выбором темы.

Репозиторий: https://github.com/Habiba394/slozhno-sosredotochitsya-ad

## Что реализовано

- семантическая вёрстка: `header`, `main`, `section`, `article`, `footer`, один заголовок `h1` и многоуровневые заголовки;
- адаптивность по принципу mobile first: базовые стили для мобильных экранов, медиавыражения `width >= 768px` и `width >= 1024px`;
- сетка на `grid`: разметка секций, карточек и галереи, без горизонтальной прокрутки на любых размерах;
- две цветовые схемы (тёмная — основная, светлая — через `prefers-color-scheme` и классы `theme-dark`, `theme-light`, `theme-auto`);
- цвета, размеры текста и отступы вынесены в CSS-переменные;
- шрифт IBM Plex Mono подключён через `@font-face`;
- состояния ссылок и кнопок: `:hover`, `:focus-visible`, активная кнопка темы;
- декоративные элементы (уголки, индикатор REC) сделаны псевдоэлементами и скрыты от скринридеров;
- картинки галереи с `alt`, размерами и ленивой загрузкой.

## Структура

```
.github/workflows/   автоматическая проверка
fonts/               шрифты и fonts.css
images/              картинки и фавиконки
scripts/             скрипт переключения темы
styles/
  globals.css        сброс и глобальные стили
  variables.css      переменные и их адаптивные значения
  style.css          основные стили (тёмная тема) и адаптив
  dark.css           переопределения для класса theme-dark
  light.css          светлая тема
index.html
```

## Запуск

Откройте `index.html` в браузере. Сборка не требуется.
